# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

We take the security of automated financial systems and trading gateways seriously.

If you discover a security vulnerability or algorithmic risk flaw:
1. Please do not open a public GitHub issue.
2. Draft a detailed security report outlining:
   - Description of the vulnerability.
   - Steps to reproduce.
   - Potential impact on model inference or trading execution safety.
3. Submit the report directly via GitHub Security Advisories or to the repository maintainer.
4. We will review and provide a patch within 48 hours.
